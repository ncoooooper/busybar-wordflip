# WordFlip

Learn 50 everyday Spanish words with reversible flashcards and review intervals based on recall.

Click to reveal a translation. Turn to select Again, Good or Easy, then click to grade. Again returns in one minute. Good and Easy schedule increasingly distant reviews (up to 45 days). Turn on the prompt to browse due cards; Start reverses English and Spanish. Progress is saved locally.

## Run locally

From this folder, run `~/.busy-emulator/bin/busy-emulator dev --once` with BUSY Bar Emulator open. Back exits.
